# Glow

**Gradient aura on deep space.**

Radial-gradient dark background (deep purple fading to near-black), soft violet glow orb behind a lavender-to-cyan gradient letter, thin outer ring. Signals "modern AI / agent / generative" without being literal about it.

## Fit

- AI / Agent / LLM-adjacent projects
- Creative tools, generative systems
- Projects where "future-facing" is part of the positioning

## Typography

Display: **SF Pro Display / Inter** (clean geometric sans for the contrast with glow effects). Mono: **JetBrains Mono**.

## Icons

Lucide outline with `currentColor` — picks up the brand violet against dark surfaces.

This is the canonical Meridian home style — Meridian's own site (`docs/.vitepress/theme/style.css` + `docs/public/hero.svg`) is rendered in this style.
