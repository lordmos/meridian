# Retro-Terminal

**Amber phosphor, dashed frame, 80s CRT.**

CRT-dark background with a radial amber glow, dashed amber frame, four cardinal tick markers outside the frame, bitmap-style letter in amber with a subtle bloom filter. Unapologetically retro.

## Fit

- Nostalgic / demoscene projects, retro-computing tools
- Games, emulators, chiptune / tracker adjacent work
- Projects that want to feel hand-hewn or hacker-folklore

## Typography

Display & mono both **VT323** (a Google-hosted CRT bitmap font). Falls back to Courier. Text looks best at larger sizes; set body text minimum 16px to avoid shimmer.

## Icons

Lucide outline in amber, or bitmap-style custom icons when the project leans fully into the aesthetic.
