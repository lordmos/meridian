# Dev-native

**Terminal, but legible.**

Rounded near-black frame with four L-corner brackets as the compass motif, mono letter in neon cyan, static cursor block underneath. Reads like a terminal window even in a list of logos.

## Fit

- CLI tools, shell utilities, build systems
- Developer infrastructure, SDKs
- Projects whose primary audience lives in a terminal

## Typography

Display = mono, everywhere. **JetBrains Mono** preferred; falls back to system mono. No proportional sans in this style — the consistency is the point.

## Icons

Lucide outline, often paired with ASCII-style glyphs (`>`, `$`, `~`) in body copy.
