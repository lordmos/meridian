# Quick Start

## Three Steps

### Step 1 — Get Meridian

```bash
git clone https://github.com/lordmos/meridian.git
cd meridian
```

Or [download ZIP](https://github.com/lordmos/meridian/archive/refs/heads/main.zip) and extract.

### Step 2 — Open the directory and say this one sentence

Open the Meridian directory in an AI tool (Claude Code / Cursor / Windsurf, etc.) and say:

> Please read my project. The project directory is at `[your project path]`. Understand the project and set up the operations infrastructure for it.

### Step 3 — AI completes everything automatically

The AI will first explore your project, then propose 3 color schemes for you to choose from, and list existing README issues. After confirmation, the AI executes the full operations workflow.

You only need to do three things:

1. **① Answer initial questions** — AI will ask for your GitHub info, etc.
2. **② Choose a color scheme** — Pick one from 3 randomly generated options
3. **③ Review the results** — Check the generated files

## Resume After Interruption

If the session is interrupted, reopen your AI tool and say:

```
Please read checkpoint.md and continue the unfinished work.
```
