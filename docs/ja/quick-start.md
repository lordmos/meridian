# クイックスタート

## 3ステップで始める

### Step 1 — Meridian を入手する

```bash
git clone https://github.com/lordmos/meridian.git
cd meridian
```

または [ZIP をダウンロード](https://github.com/lordmos/meridian/archive/refs/heads/main.zip) して解凍。

### Step 2 — ディレクトリを開いて、この一文を入力

AI ツール（Claude Code / Cursor / Windsurf など）で Meridian ディレクトリを開き、次の一文を入力してください：

> 私のプロジェクトを読んでください。プロジェクトディレクトリは `[プロジェクトパス]` です。プロジェクトを理解して、運営基盤を整えてください。

### Step 3 — AI がすべてを自動で完了

AI がプロジェクトを探索した後、3 つのカラースキームを提案し、README の問題点をリストアップします。確認後、AI がすべての運営タスクを実行します。

あなたが行う作業は 3 つだけ：

1. **① 初期質問に回答** — AI が GitHub 情報などを確認
2. **② カラースキームを選択** — ランダム生成された 3 つから選ぶ
3. **③ 成果物を確認** — 生成されたファイルをチェック

## 中断後の再開

セッションが中断された場合、AI ツールを再起動して次を入力：

```
checkpoint.md を読んで、未完了の作業を続けてください。
```
