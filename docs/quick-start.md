# 快速开始

## 三步上手

### Step 1 — 获取 Meridian

```bash
git clone https://github.com/lordmos/meridian.git
cd meridian
```

或直接 [下载 ZIP](https://github.com/lordmos/meridian/archive/refs/heads/main.zip) 解压。

### Step 2 — 打开目录，说这一句话

用 AI 工具（Claude Code / Cursor / Windsurf 等）打开 Meridian 目录，然后说：

> 请你阅读我的项目，项目目录在 `[你的项目路径]`，理解这个项目，给这个项目做一下运营配套。

### Step 3 — AI 自动完成所有工作

AI 会先探索你的项目，然后提案 3 个配色方案让你选择，并列出 README 现存问题。你确认后，AI 自动执行全套运营任务。

你只需要做三件事：

1. **① 回答初始问答** — AI 会询问你的 GitHub 信息等
2. **② 选择配色方案** — 从 3 个随机生成的方案里选一个
3. **③ 验收成果** — 检查生成的文件

## 中断后恢复

如果会话中断，重新打开 AI 工具并说：

```
请读 checkpoint.md，继续上次未完成的工作。
```
