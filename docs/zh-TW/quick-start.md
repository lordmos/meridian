# 快速開始

## 三步上手

### Step 1 — 取得 Meridian

```bash
git clone https://github.com/lordmos/meridian.git
cd meridian
```

或直接 [下載 ZIP](https://github.com/lordmos/meridian/archive/refs/heads/main.zip) 解壓縮。

### Step 2 — 開啟目錄，說這一句話

用 AI 工具（Claude Code / Cursor / Windsurf 等）開啟 Meridian 目錄，然後說：

> 請你閱讀我的專案，專案目錄在 `[你的專案路徑]`，理解這個專案，給這個專案做一下運營配套。

### Step 3 — AI 自動完成所有工作

AI 會先探索你的專案，然後提案 3 個配色方案讓你選擇，並列出 README 現存問題。你確認後，AI 自動執行全套運營任務。

你只需要做三件事：

1. **① 回答初始問答** — AI 會詢問你的 GitHub 資訊等
2. **② 選擇配色方案** — 從 3 個隨機生成的方案裡選一個
3. **③ 驗收成果** — 確認生成的檔案

## 中斷後恢復

如果會話中斷，重新開啟 AI 工具並說：

```
請讀 checkpoint.md，繼續上次未完成的工作。
```
