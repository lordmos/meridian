## 使用规则

1. **先查表再翻译**：遇到任何术语，先搜本文件。
2. **发现新术语立即回写**：首次遇到未收录术语，加入对应分类并更新 `Maintained` 日期。
3. **修改已收录译法需同步**：改动一条，需四语言 README + docs 全部同步。
4. **章节标题一律走 C 节**：不得自创。
5. **触发句和恢复句一字不改**：这两句是 Meridian 的核心 UX，D 节的四语言版本不得私自修改。
